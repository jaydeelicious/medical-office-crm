Medical Office CRM API — manage patients, doctors, and appointments, with conflict prevention and basic scheduling rules.

The initial domain can be:

Patient
- Id
- FirstName
- LastName
- Phone
- Email
- DateOfBirth

Doctor
- Id
- FirstName
- LastName
- Specialty

Appointment
- Id
- PatientId
- DoctorId
- StartTime
- EndTime
- Status
- Notes

public enum AppointmentStatus
{
    Scheduled,
    Completed,
    Cancelled,
    NoShow
}

The first useful endpoints: 

POST   /api/patients
GET    /api/patients/{id}
GET    /api/patients?search=Papadopoulos
PUT    /api/patients/{id}

POST   /api/doctors
GET    /api/doctors

POST   /api/appointments
GET    /api/appointments/{id}
GET    /api/appointments?date=2026-09-27
PUT    /api/appointments/{id}/reschedule
PATCH  /api/appointments/{id}/status


A doctor cannot have two active appointments
whose time ranges overlap.
